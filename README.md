# Базовые SQL-запросы. Домашнее задание 18.2

Реализованы базовые SQL-запросы для работы с учебной базой данных Northwind.

## Выполненные задачи

- **simple_queries.sql**: Простые выборки, подсчет количества, уникальные значения.
- **filter_sorting.sql**: Фильтрация по списку и диапазону, сортировка, агрегатные функции (AVG, MIN, MAX).
- **groupby.sql**: Группировка, фильтрация после группировки (HAVING), шаблоны (LIKE), пересечение множеств (INTERSECT/EXCEPT).

## Как проверить

1. Откройте базу данных `northwind` в pgAdmin.
2. Запустите скрипты из папки `sql/` через «Инструмент запросов».
3. Результаты соответствуют скриншотам из эталонного задания.
